# Telegram diary questionnaire for Notion

Личный Telegram-бот создаёт страницу в Notion и задаёт вопросы по редактируемым полям базы. Ответы записываются по мере прохождения опроса.

## Установка

Нужны Python 3.11 или новее, собственный токен BotFather и интеграция Notion с правами чтения и записи в вашу базу.

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Заполните `TELEGRAM_TOKEN`, `NOTION_TOKEN`, `DATABASE_ID` и `ALLOWED_USER_ID`. Последнее поле — ваш числовой Telegram ID. Бот принимает сообщения только от этого пользователя в личном чате. В `TIMEZONE` укажите часовой пояс IANA, например `UTC`.

## Настройка Notion

Предоставьте интеграции доступ к базе. Поддерживаются заголовок, текст, число, выбор одного или нескольких вариантов, дата и флажок. Формулы, связи и другие вычисляемые поля пропускаются.

Названия полей становятся вопросами; порядок следует схеме, полученной от API. Личный опросник и примеры записей дневника в репозиторий не входят.

Сохранён исходный API базы с `Notion-Version: 2022-06-28`. Используйте базу с одним источником данных. Для новых баз с несколькими источниками нужна миграция на data-source API: [инструкция Notion](https://developers.notion.com/docs/upgrade-guide-2025-09-03).

## Запуск

```powershell
./start_bot.bat
```

| Команда | Действие |
|---|---|
| `/start` | Показать справку |
| `/run_task_manually` | Создать страницу и начать опрос |
| `/schedule HH:MM` | Установить или заменить ежедневное напоминание |
| `/cancel` | Прекратить текущий опрос; созданная страница остаётся в Notion |

## Ограничения и данные

Для напоминаний процесс должен работать. Расписание и состояние опроса хранятся в памяти и теряются при перезапуске: команду `/schedule` нужно повторить. Первую проверку проводите в отдельной тестовой базе.

Ответы передаются Telegram и Notion. Журнал остаётся локальным и может содержать подробности ошибок; не публикуйте его. Ключи, SSH-ключи, журналы и персональные названия полей исходного проекта исключены из публичной версии. Создана новая Git-история.

## Проверки

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты проверяют личный доступ, создание приложения, расписание с правильным контекстом чата, начало опроса и запись ответов. После неудачной записи бот остаётся на текущем вопросе; после завершения очищает состояние. Реальная доставка Telegram и права Notion не проверялись. Документация расписания: [JobQueue](https://docs.python-telegram-bot.org/en/stable/telegram.ext.jobqueue.html).
